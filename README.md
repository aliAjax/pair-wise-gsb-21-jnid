# hxwl-07 航空维修检查清单

按ATA章节推进维修放行前检查

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 功能

### 业务流程

```
维修工程师录入检查项 ──提交复核──▶ 待复核
                                    │
              放行人员复核 ◀──────────┘
              ├── 放行 ──▶ 已放行（记录锁定，不可再修改）
              └── 退回 ──▶ 已退回 ──工程师修改后重新提交──▶ 待复核
```

- **录入（维修工程师）**：填写机型、ATA章节、检查区域、检查项目、检查结果、签署人，
  提交后保存为「待复核」；缺陷项必须填写缺陷描述和处理意见才能提交复核。
- **复核（放行人员）**：对待复核记录选择「放行」或「退回」；退回必须填写退回意见。
- **放行锁定**：已放行的记录锁定，不能再编辑或删除。
- **退回重报**：被退回的记录由工程师修改后重新提交，状态回到「待复核」，流转记录全程留痕。

### 数据与统计

- 检查记录保存在浏览器 localStorage，重开页面不丢失；支持一键导出 JSON、清空本地数据。
- 按 ATA 章节统计各章节的缺陷项数量，点击章节可联动筛选记录列表。
- 指标看板实时统计完成率（已放行占比）、缺陷项、待复核、涉及 ATA 章节数。
- 支持按状态、检查区域、ATA 章节筛选记录。

### 角色

页面右上角切换「维修工程师 / 放行人员」角色，不同角色看到的操作不同；
工程师与复核人姓名会记住，下次自动填充。
